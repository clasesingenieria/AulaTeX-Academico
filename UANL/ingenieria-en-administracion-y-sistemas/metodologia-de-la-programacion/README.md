- `reporte-metodologia-de-la-programacion-Actividad-2.tex`: reporte con portada, instrucciones, análisis, algoritmos y bloques de código.

- El PDF se genera junto al archivo TeX mediante `aulaTEX/latexmk-build.ps1`.

## Uso en Dev-C++

Abra un archivo `.cpp` como código fuente, compile y ejecute. Cada programa contiene su propia función `main`, por lo que no deben agregarse todos al mismo proyecto simultáneamente.

Para validar el lote completo desde Windows, ejecute `ejecutar-pruebas-actividad-2.bat`. Se requiere que `g++` esté disponible en `PATH`.
