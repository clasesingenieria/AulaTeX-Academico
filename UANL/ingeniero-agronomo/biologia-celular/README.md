# Biología celular - Ingeniería en Agronomía

[Consultar las guías de estudio](guias-biologia-celular.md).

El conjunto incluye seis guías conceptuales Markdown con definiciones, mecanismos paso a paso, cuadros comparativos, 120 preguntas con sus respuestas y una tabla de 64 codones, además de las 90 capturas de las referencias. Todas las capturas cuentan con un [dictamen de revisión](capturas-referencias.md#auditoría-de-las-90-capturas). El texto permite estudiar los temas de las referencias sin depender de imágenes ilegibles; la cobertura del examen oficial debe contrastarse con su temario. La práctica integradora se conserva como complemento independiente. Las presentaciones, PDF e imágenes originales se conservan en [referencias](referencias/).
