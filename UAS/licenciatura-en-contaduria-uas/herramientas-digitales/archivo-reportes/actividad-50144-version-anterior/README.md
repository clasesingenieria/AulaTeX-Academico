# Versiones anteriores de la actividad 50144

Los archivos de esta carpeta se apartaron durante la normalización de nombres
del 11/11/2026. El sitio web es la actividad Moodle 50144; `Actividad-6`
corresponde a otra actividad local (acceso a Zoom), por lo que el reporte web
con esa etiqueta no debe usarse como reporte de Zoom.

- `reporte-50144-version-anterior.tex`: fuente breve previa al reporte paso a
  paso con memoria gráfica.
- `reporte-50144-anterior-rotulado-Actividad-6.tex`: borrador web extenso con
  nombre local incorrecto.
- `reporte-50144-anterior.pdf` y `GPO103_LCP_WEB_MartinJonathan_DeLaCruzMunoz.pdf`:
  copias históricas del borrador anterior.
- `GPO103_LNCI_WEB_version-anterior.pdf`: versión de entrega previa a la
  memoria gráfica actual.

La entrega activa se identifica por el módulo 50144 y está en la raíz y en
`../../entregas-herramientas-digitales/`.
