## 2. Base Conceptual Rigurosa (`conceptos_clave`)

### 2.1. Modelado de determinantes de ventas

- **Definición rigurosa**: El modelado de determinantes de ventas implica la identificación y cuantificación de variables que influyen en las ventas de una organización. Utilizando técnicas de regresión, se pueden estimar los efectos de variables como precios, promociones y competidores sobre las ventas. Este modelo permite a los gerentes entender mejor las dinámicas del mercado y ajustar estrategias en consecuencia.
- **Formulación matemática (LaTeX)**: `$$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 +... + \beta_nX_n + \epsilon$$`
- **Aplicación administrativa**: Los gerentes pueden usar este modelo para predecir ventas futuras bajo diferentes escenarios de precios y promociones, optimizando así sus estrategias de marketing y ventas.
- **Fuente principal**: Anderson, Sweeney y Williams, 2012 (bloque 3)

### 2.2. Precios y elasticidad comercial

- **Definición rigurosa**: La elasticidad comercial mide la sensibilidad de la demanda de un producto a cambios en su precio. Se calcula como el porcentaje de cambio en la cantidad demandada dividido por el porcentaje de cambio en el precio. Una elasticidad mayor a 1 indica que la demanda es elástica, mientras que una menor a 1 indica que es inelástica.
- **Formulación matemática (LaTeX)**: `$$E_p = \frac{\Delta Q/Q}{\Delta P/P}$$`
- **Aplicación administrativa**: Entender la elasticidad del precio ayuda a los gerentes a establecer estrategias de fijación de precios que maximicen las ganancias.
- **Fuente principal**: Lind, Marchal y Wathen, 2012 (bloque 3)

### 2.3. Estimación de funciones de costos y productividad organizacional con regresión múltiple

- **Definición rigurosa**: La regresión múltiple permite estimar la relación entre una variable dependiente (como costos o productividad) y varias variables independientes. Este modelo es útil para identificar los factores que más influyen en los costos y la productividad, permitiendo a los gerentes tomar decisiones informadas para optimizar estos aspectos.
- **Formulación matemática (LaTeX)**: `$$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 +... + \beta_nX_n + \epsilon$$`
- **Aplicación administrativa**: Los gerentes pueden usar este modelo para identificar áreas de ineficiencia y tomar medidas para reducir costos y mejorar la productividad.
- **Fuente principal**: Wackerly et al., 2010 (bloque 3)

### 2.4. Evaluación del desempeño financiero y compensación ejecutiva mediante modelos lineales

- **Definición rigurosa**: Los modelos lineales se utilizan para evaluar el desempeño financiero de una organización y determinar la compensación ejecutiva. Estos modelos permiten identificar la relación entre el desempeño financiero y variables como las ventas, los costos y la rentabilidad.
- **Formulación matemática (LaTeX)**: `$$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 +... + \beta_nX_n + \epsilon$$`
- **Aplicación administrativa**: Los gerentes pueden usar estos modelos para establecer sistemas de compensación que incentiven el desempeño financiero de la organización.
- **Fuente principal**: Anderson, Sweeney y Williams, 2012 (bloque 1)

### 2.5. Diagnóstico de supuestos clásicos de Gauss-Markov

- **Definición rigurosa**: Los supuestos clásicos de Gauss-Markov son un conjunto de condiciones que deben cumplirse para que los estimadores de mínimos cuadrados ordinarios (MCO) sean los mejores estimadores lineales insesgados (BLUE). Estos supuestos incluyen linealidad, homocedasticidad, normalidad, independencia y ausencia de multicolinealidad.
- **Formulación matemática (LaTeX)**: `$$E(\epsilon) = 0, Var(\epsilon) = \sigma^2I, Cov(\epsilon, X) = 0$$`
- **Aplicación administrativa**: Verificar estos supuestos es crucial para garantizar la validez y fiabilidad de los modelos de regresión utilizados en la toma de decisiones gerenciales.
- **Fuente principal**: Lind, Marchal y Wathen, 2012 (bloque 1)

### 2.6. Uso de variables dicotómicas para evaluar intervenciones administrativas

- **Definición rigurosa**: Las variables dicotómicas son variables que pueden tomar solo dos valores, típicamente 0 y 1. Se utilizan en modelos de regresión para representar la presencia o ausencia de una intervención o característica específica. Esto permite evaluar el impacto de dichas intervenciones en variables dependientes como ventas, costos o productividad.
- **Formulación matemática (LaTeX)**: `$$Y = \beta_0 + \beta_1X_1 + \beta_2D + \epsilon$$`
- **Aplicación administrativa**: Los gerentes pueden usar variables dicotómicas para evaluar la efectividad de intervenciones como cambios en la política de precios, lanzamientos de nuevos productos o implementaciones de programas de capacitación.
- **Fuente principal**: Wackerly et al., 2010 (bloque 1)

### 2.10. Mínimos cuadrados

- **Definición rigurosa**: El método de mínimos cuadrados es una técnica estadística utilizada para estimar los parámetros de un modelo de regresión. El objetivo es minimizar la suma de los cuadrados de las diferencias entre los valores observados y los valores predichos por el modelo.
- **Formulación matemática (LaTeX)**: `$$S = \sum_{i=1}^{n} (Y_i - \hat{Y_i})^2$$`
- **Aplicación administrativa**: Los gerentes pueden usar el método de mínimos cuadrados para estimar los parámetros de modelos de regresión que predicen ventas, costos o productividad, y para tomar decisiones informadas basadas en estos modelos.
- **Fuente principal**: Lind, Marchal y Wathen, 2012 (bloque 2)
