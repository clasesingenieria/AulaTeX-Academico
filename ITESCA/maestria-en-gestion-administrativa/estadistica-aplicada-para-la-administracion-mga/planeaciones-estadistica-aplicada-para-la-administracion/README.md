## Integracion documental

Se integraron 299 archivos de importaciones y antecedentes, incluyendo 97 revisiones. No se conservan esas carpetas ni se crean respaldos nuevos.

Los documentos identicos se almacenan una sola vez dentro de cada modelo. Se conservan sus contenidos completos, hashes y correspondencias; las capturas y revisiones previas no se tratan como requisitos nuevos ni como aprobaciones.

## Bloqueos academicos

La Actividad 7 conserva conflicto de extension (3 paginas frente a 3 cuartillas sin portada ni fuentes), escala oficial no verificada y comprobacion pendiente de portada/producto. Las otras 21 actividades mantienen integracion academica pendiente.

## Calendario y acceso

Fechas operativas sin programar. Una fecha vacia no acredita apertura ni autoriza envios. Moodle es una integracion opcional.

## Validacion y vistas

El auditor local comprueba modelos, fuentes integradas, enlaces y vistas. La opcion `--render-views` regenera Markdown desde JSON; no ejecuta actividades. `--consolidate-folders` absorbe las dos carpetas y verifica su integridad antes de eliminarlas.
