## Criterios de actualizacion

Las planeaciones derivadas deben separar requisitos publicados de propuestas de trabajo. Cada requisito conserva URL, localizador y fecha de consulta; lo no visible permanece pendiente. Una consulta no equivale a aprobacion docente.

No iniciar cuestionarios, responder foros ni entregar archivos durante la recopilacion. No copiar credenciales, cookies, enlaces privados de reuniones, calificaciones o datos de participantes a los documentos. Los originales y las revisiones previas se preservan.
