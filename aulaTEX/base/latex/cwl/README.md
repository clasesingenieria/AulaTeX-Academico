# Definiciones CWL

Archivos de autocompletado (`.cwl`) para los comandos de las plantillas Template-Latex.
LaTeX Workshop los carga mediante `latex-workshop.intellisense.package.dirs` en `.vscode/settings.json`.

Rescatados de la antigua rama `master` (`herramientas/latex/cwl-docs/cwl/`) antes de su eliminación.
