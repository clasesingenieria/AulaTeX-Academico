# Datos de entrenamiento

- `data/private/`: corpus real y particiones; nunca se versiona.
- `data/samples/`: únicamente ejemplos sintéticos o anonimizados pequeños.
- Los documentos deben ser propios, autorizados o tener licencia compatible.
- Antes de exportar se ejecuta el escáner de privacidad y se revisan manualmente los hallazgos.
