# Universidad Autónoma de Coahuila (UAdeC)

Este directorio organiza material local relacionado con la [UAdeC](https://www.uadec.mx/). La presencia de una carpeta no acredita matrícula, aprobación institucional ni correspondencia con un plan curricular vigente.

## Estado de organización

Médico Cirujano contiene ocho áreas de preparación para ingreso con plantilla compartida, dos actividades por área, productos TEX/PDF y bancos de práctica. [Alcance, estructura y controles de calidad](medico-cirujano/README.md).

La convocatoria, el campus y el temario oficial aplicable permanecen pendientes de cotejo. No se inventan asignaturas, fechas de entrega, datos de aspirante, requisitos de envío ni resultados de exámenes.
